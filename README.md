# SampleSYS downloads

Public downloads for SampleSYS from 3DIGIT: a free sampler that builds ROM sounds for SynthSYS.
Get it from [3digitsamples.com](https://3digitsamples.com), or through AuthSYS. This repository
holds release files only.

| Download | File |
|---|---|
| SampleSYS, macOS (Apple Silicon) | `SampleSYS-<version>-AppleSilicon.dmg` |
| SampleSYS, macOS (Intel) | `SampleSYS-<version>-Intel.dmg` |

Open the disk image and drag SampleSYS to Applications.

Until the Developer ID certificate comes through these are unsigned, so macOS refuses them the
first time: open Privacy & Security in System Settings, scroll to the bottom, choose Open Anyway,
then open the image again. Downloads handed over by AuthSYS are not refused this way — only ones
fetched with a browser.
